## NevGThree — game 3D untuk Nev.js 🎮

Rilis ini memperkenalkan **NevGThree** (`@adityadevid/nevgthree` 0.1.0): lapisan 3D untuk NevG di atas three.js. Loop, scene, entity, input, tween, dan timer sama dengan NevG, tapi dunianya 3D. Tetap tanpa build step.

### Baru
- **`Game3D` / `Scene3D`** — renderer WebGL, resolusi adaptif (turun otomatis di HP yang berat), `setQuality('low'|'medium'|'high')`, lampu + bayangan, kabut, `pick()` / `raycast()`, camera shake.
- **`Entity3D` / `Mesh3D` / `Model3D`** — objek 3D dengan kotak tabrakan, tag, anak-induk, animasi `spin` / `bob`, dan pembersihan GPU otomatis.
- **`Body3D`** — fisika arcade: gravitasi, lompat (coyote time + jump buffer), naik lereng dan tangga kecil.
- **Kamera** — `OrbitRig`, `TopDownRig`, `FirstPersonRig`, dengan gerak relatif kamera.
- **`Controls3D`** — WASD, mouse, dan **joystick sentuh + tombol layar** untuk HP.
- **Dunia prosedural** — `Terrain` (pulau low-poly, `heightAt()` presisi), air, langit, pohon, batu, kristal, awan, karakter blocky, `Particles3D`.
- **`extendAssets`** — `assets.texture()` dan `assets.gltf()`.

### Nev (fullstack)
- Template baru: `npx @adityadevid/nevjs create game-saya --template game3d` → **Crystal Run 3D** (kumpulkan kristal, combo, dash, skor terbaik tersimpan, HUD NevF).
- `three` dan `three/addons/` dilayani ke browser lewat import map, termasuk di `nev export`.
