Latar — stagger grid

Latarnya adalah demonya.

Pola latar diganti berkala oleh satu rantai animasi: gelombang radial dari tengah, sapuan sumbu-X, denyut dari sudut, dan acak — semuanya dari satu primitif yang sama, stagger(nilai, { grid: [baris, kolom], from }). Klik di mana pun pada halaman untuk riak dari titik klik; tombol di bawah memicu pola tertentu ke seluruh grid.

animate('#bg i', {
  scale: [ { to: .25, duration: 380 }, { to: 1, duration: 620, ease: 'easeOutBack' } ],
  backgroundColor: [ { to: '#ff4b33', duration: 380 }, { to: '#17171a', duration: 620 } ],
  delay: stagger(26, { grid: [rows, cols], from: 'center' }),
});
Lab 01 — Easing

Delapan easing, satu garis finis.

Semua titik berangkat bersamaan dengan durasi yang sama; yang membedakan hanya kurvanya. Perhatikan spring — ia melampaui finis lalu kembali menetap, karena ia simulasi fisika, bukan kurva — dan steps yang bergerak bertahap.

spring selesai saat pegasnya menetap, bukan saat durasi habis
Lab 02 — Keyframes

Squash & stretch, dan blob yang berputar.

Karakter di kiri bergerak murni dari keyframes: antisipasi, lompat, mendarat. Blob di kanan menganimasikan border-radius, rotasi, dan sudut conic-gradient lewat CSS variable --a — tiga jenis nilai dalam satu panggilan animate().

keyframes · css var · color
Lab 03 — Timeline

Satu hari, disutradarai satu timeline.

Fajar → siang → senja → malam ditulis sebagai satu createTimeline() berlabel. Geser slider-nya: seek() deterministik — posisi matahari, warna langit, dan bintang selalu persis sama di milidetik yang sama, maju maupun mundur.
